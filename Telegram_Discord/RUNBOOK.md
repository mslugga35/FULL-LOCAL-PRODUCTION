
```powershell

```

## 6) Toggle OCR
Edit `config\settings.yaml` → `ocr.enabled: true` (requires google-cloud-vision & credentials).

## 7) Cleanup & Retry
- `scripts\clean_archive.bat` compresses old archive and prunes media.
- `scripts\retry_failed.bat` re-queues failed payloads.

## 8) Quick Start/Stop
```powershell
# Start all services
.\start_all.bat

# Stop all services
.\stop_all.bat
```

## 9) Configuration Files
- `config\channel_routing_map.py` - Maps Telegram channel IDs to Discord targets
- `config\discord_targets.yaml` - Discord delivery configuration (webhook vs bot)
- `config\settings.yaml` - General settings (OCR, paths, batch sizes)
- `.env` - Environment variables (API keys, tokens, webhooks)

## 10) Environment Variables Required
- `TELEGRAM_API_ID` - Your Telegram API ID
- `TELEGRAM_API_HASH` - Your Telegram API hash
- `TELEGRAM_SESSION_STRING` - Generated by make_session.py
- `DISCORD_WEBHOOK_PAID` - Webhook URL for paid channels
- `DISCORD_BOT_TOKEN_FREE` - Bot token for free channels

## 11) Troubleshooting
- Check PM2 status: `pm2 status`
- View logs: `pm2 logs tg-collector` / `pm2 logs router` / `pm2 logs forwarder`
- Restart service: `pm2 restart tg-collector`
- Test Discord connectivity: Run test_forward.py with different queues
